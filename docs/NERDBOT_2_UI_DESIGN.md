# Nerdbot 2.0 UI Design

## Direction

Outcome-first AI work environment. Not an internal engineering console.

## Primary workspace navigation

- **Overview** - what is happening, completed, needs attention, blocked, decisions needed, deliverables, next action.
- **Work** - objectives/tasks with owner, status, progress, blockers, deliverables, evidence, decisions required, next action.
- **Chat** - delegate/clarify/follow up in workspace context.
- **Library** - docs/knowledge/reports/research/deliverables.
- **Agents** - collaborators with role, current responsibility, activity, availability, capabilities, relevant history, deliverables, permissions/autonomy, pause/resume.

## Progressive disclosure

Advanced/secondary: Teams, Boards, Workbench/Code mode, Execution diagnostics, Administration, Detailed event streams. Raw logs/run IDs/SSE diagnostics available but not default.

## Design quality bar

Clear hierarchy, strong typography, consistent spacing, thoughtful density, responsive layouts, useful empty/loading/error states, accessible contrast/keyboard behavior, subtle motion only when it aids comprehension. Preserve React/Vite/Tailwind stack.
