# Product Vision

NerdBot is a self-hosted AI operating workspace: describe an outcome, NerdBot plans, specialist agents execute, the system verifies, you receive result + evidence.

Primary destinations: Home (command), Work (tasks), Agents, Approvals, Settings. Workspaces/boards/teams contextual.

Bits = small autonomous units (bot, task, schedule); workspace orchestrates them.

Principles: one request→result loop; no mock data; truthful status; approval-gated destructive ops; durable task state; single agent default, specialists only when needed.
