## Clean-room statement for Odysseus-derived code

All code in `~/nerdbot` that is inspired by Odysseus (AGPL-3.0-or-later) has
been re-implemented from behavioral description only. No source files, strings,
constants, or data structures from `~/odysseus` have been copied, translated, or
derived by mechanical transformation. Where a detail mattered, the cited file
was read to *understand the behavior*, then fresh **Python** was written (the
backend is Python 3.12; an earlier draft of this file said TypeScript, which no
longer reflects the implementation). Marker strings differ deliberately — for
example Nerdbot uses `<<<UNTRUSTED_RUN_OUTPUT>>>`, not the source's marker.
This stance is documented here and in `THIRD_PARTY_NOTICES`.

## Xiryn (MIT) — reference and reuse policy

Source: `~/nerdbot-refs/xiryn` (MIT). Xiryn is used as the functional
reference for capability work: isolated per-agent computer environments,
human takeover/hand-back, Telegram control, and speech input/output. Because
Xiryn is MIT, components may be reused where technically appropriate; any
verbatim or substantially copied file must carry the Xiryn MIT notice in
`THIRD_PARTY_NOTICES` and in the file itself. Concepts re-implemented
independently do not trigger the notice requirement, but are still logged here.
